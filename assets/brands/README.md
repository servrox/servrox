# Profile brand assets

Original artwork copied for this profile on 2026-10-23. Ownership of these
marks and illustrations remains with their respective brands. These assets
are separate from the upstream Galaxy Profile artwork.

- `agent-skills.svg`, `chatgpt-plugin-badge.svg`: [Agent Skills](https://github.com/stark-ai-de/agent-skills/tree/main/docs/assets), original static logo and plugin badge.
- `stark-ai-light.svg`, `stark-ai-dark.svg`: original horse and wordmark from the company website's `packages/stark-ui/assets/logo.svg` and `logo-dark.svg`. Preserve the blue accent and original paths. Brand: [stark AI](https://stark-ai.de/en).
- `servrox-light.svg`, `servrox-dark.svg`: original `round-white-s-black-background.svg` and `round-black-s-white-background.svg` from the servrox solutions website's `public/logos` directory. Brand: [servrox solutions](https://servrox.solutions/).
- `mr-peeltos.png`: transparent `apps/platform/public/assets/character_1.png`, resized proportionally to 240 px high for the profile (original artwork and alpha preserved) from the Panana project. Character: Mr. Peeltos, [Panana Predictions](https://panana.fun/).

and destinations also appear as Markdown text.
